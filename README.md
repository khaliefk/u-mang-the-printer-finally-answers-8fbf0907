One line, written as the office printer's comeback to everyone who jams it, thumps it, and stares at its error codes.

`main.py` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).

## Run

```sh
python3 main.py
```
